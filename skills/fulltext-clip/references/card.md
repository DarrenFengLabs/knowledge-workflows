# 知识卡片

适用：用户发来的一段短文字（引文、摘抄、听到后记下的话），或提取后不到 3000 字的截图。由主对话直接做，不派子代理。

## 规则

1. **原文保真**：只改明显错别字和标点，不润色、不改措辞、不调语序。这是摘录，不是写作。
2. **英文内容**：同样做英中对照（英文小字在上、中文在下），翻译规则同 write.md。
3. **标题**：从内容提炼 5–15 字的短标题，不加 emoji 前缀。
4. **来源**：用户说明了就记录；没说明写“来源：未注明”。不推测来源或作者，引文张冠李戴是这类笔记最伤的错误。
5. **排版**：可用“内容概览”“原文摘录”等中性小标题；不加评论、不加解读、不自行发挥标签。人名不加粗。

## 之后

按 storage.md 以 `标题.md` 写入输出目录；同名不覆盖，先问用户。
