# 知识卡片(模式 D)

适用:用户发来的一段短文本——引文、摘抄、听到后记下的话。

## 处理规则

1. **原文保真**:只改明显错别字和标点,不润色、不改措辞、不调语序。这是摘录,不是写作
2. **英文内容**:同样做英中对照(原文段 + 译文段),翻译规则同 `optimize.md`
3. **生成标题**:从内容提炼 5–15 字短标题(不加任何 emoji 前缀)
4. **来源**:用户说明了就记录;没说明则写「来源:未注明」。**严禁推测来源或作者**——引文张冠李戴是这类系统最伤的错误
5. 排版成方便阅读的形式:可用「内容概览」「原文摘录」等中性小标题,但不加评论、不加解读、不自行发挥标签
