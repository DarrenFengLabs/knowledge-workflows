# notes-with-media · 使用说明

把**转写 + 你的手写笔记 + 截图/照片/课件/资料**融合成**看笔记就能替代听音频、也替代翻截图**的结构化、飞书友好 Markdown 笔记。输入路径每批不同，开工前对齐（§0）即可上手。

## 它在本项目里的位置

| skill | 干什么 | 输入 | 输出 |
|---|---|---|---|
| `fulltext-clip` | 摄入预加工 | 少量外部内容（链接/视频/截图） | 易读 .md |
| **`notes-with-media`**（本 skill） | **转写 + 手写 + 媒体融合** | **你自己的课堂/会议材料** | **讲义级笔记** |
| `reading-triage` | 批量阅读分诊 | 大批链接、聚合页、时间范围 | 导读或总纲 |
| `model-table` | 结构化沉淀 | 含型号的发布/评测 | 飞书 base 记录 |

**和 fulltext-clip 的分界**：fulltext-clip 处理**别人的成品内容**、只做忠实转换；本 skill 处理**你自己在场产生的材料**（转写 + 你的手写 + 你拍的图），要做融合、归位、交叉纠错。

## 装在哪 / 怎么触发

- 正本位置：`<仓库>/skills/notes-with-media/`。Codex 入口 `<仓库>/.agents/skills/notes-with-media` 与 Claude Code 入口 `<仓库>/.claude/skills/notes-with-media` 都是指向该正本的符号链接，不是副本。
- 触发：说"把这段转写连同我拍的截图/课件整理成笔记""帮我把这天的 ASR + 手写 + 图整理成讲义"之类，会自动加载。不确定时直接点名"用 notes-with-media 整理 XXX"。

## 目录结构

```
notes-with-media/
├── SKILL.md                # 整理流程/原则/格式/模板（当前代理执行时读取）
├── references/usage.md     # 你现在看的使用说明
└── scripts/
    ├── extract_docx.py     # 从 .docx 抽纯文本（标准库，支持多文件/glob）
    ├── extract_pptx.py     # 从课件 .pptx 按页抽文字（可带演讲者备注）
    ├── check_format.py     # 写完后的飞书强调标记体检 + 密度自检
    └── test_check_format.py  # check_format.py 的回归测试
```

## 第一次用：开工前对齐 6 件事（SKILL §0）

1. **转写**在哪、什么格式、怎么命名（含不含日期、一天几段）？
2. **笔记输出**到哪、怎么命名？
3. **手写笔记**在哪（md/html/docx，或直接是拍纸质笔记的照片）？
4. **媒体**在哪：截图/照片文件夹、课件目录；有没有顺序线索、有没有给图打过 `〔图N〕` 锚点？
5. **资料**：老师发的 vs 你自己查的（两类分开标源）。
6. **汇总文件**：总导航 / 术语表 / 资料表要不要维护（有就先读再追加、绝不重建）。

> **推荐归档**：一天一个文件夹，转写/手写笔记/图/课件/资料全往里扔，原始文件名不用改。截图工具默认按时间或序号命名，这个顺序≈讲课顺序，是免费的归位线索。**想给某张图确定归位，就在手写里那行旁写个 `〔图1〕`。**

## 媒体怎么被处理（SKILL §6 一句话版）

```
归类（自己笔记照片=重点 / 课程截图=内容 / 课件 / 资料）
  → 读图（视觉抽成文字实质，同张幻灯片多图合并）
  → 归位（① 你的锚点 → ② 按内容 → ③ 按顺序 → ④ 归不进就进"未归位"问你）
  → 融入正文（图的实质变正文/表格/代码，原位留〔截图：文件名〕指针）
  → 留痕（末尾"媒体清单"表，导飞书时按它贴图）
```

- ⭐ **截图/课件反向纠错**：易错事实可信度 **截图/课件 ＞ 手写 ＞ 转写**。一张写「Claude Code」的图能把转写的「克劳德扣的」坐实纠正。
- **飞书贴图**：本地路径 `![](./x.png)` 在飞书不渲染，所以正文写文字实质 + 留指针，你导入时照媒体清单手动拖图。

## 脚本怎么用（你也可手动跑）

```bash
cd <skill 目录>

# 1) 抽取转写 docx（单个 / 一个单元多段合并）
python3 scripts/extract_docx.py "~/录音/2026_06_04_a.docx" > /tmp/u.txt
python3 scripts/extract_docx.py "~/录音/2026_06_04_*.docx" --sep -o /tmp/day.txt

# 2) 抽取课件 PPT（按页，--notes 连演讲者备注）
python3 scripts/extract_pptx.py "~/课件/第3讲.pptx" --notes > /tmp/ppt.txt

# 3) 笔记写完后体检（强调标记违规 + 密度指标）
python3 scripts/check_format.py "~/笔记/2026-06-04.md"
#   输出示例：
#   违规: 0
#   斜体: 28 | 金句块: 12 | 表格: 3 | 字数: 9000
#   —— 违规必须为 0；斜体/金句/表格看是否和当天内容量匹配，偏少就回去补。
```

`check_format.py` 在有强调标记违规（失效或未闭合）时逐条列出行号，并返回退出码 1，方便串进你自己的脚本。代码块、行内代码和列表星号不会被当成强调。改了这个脚本后，运行 `python3 scripts/test_check_format.py` 确认测试仍全部通过。

## 整理出来长什么样（SKILL §8）

```
# 标题（含真实日期/场次）
> 形式/来源 + 日期核对说明
## 🗺️ 速览        ← 树状脑图 + "带走三点"，30 秒看懂
## ① 主干知识点    ← 讲义级展开；加粗结论 / >金句 / 表格；重点*斜体*；图的实质融进来 + 〔截图：x〕
## ② 行动清单      ← - [ ] checkbox（有则写）
## ③ 资料与链接    ← 课堂资料 / 我的补充 分开标
## ④ 媒体清单      ← 文件名 | 归入哪节 | 读出的要点（导飞书贴图清单）
## ⑤ 未归位媒体    ← 归不进去的图，待你认领（有才写）
## ⑥ 可信度提示    ← 存疑的数字/网址/术语集中放，不在正文散落
```

## 它替你守住的几条"硬规矩"

- **全覆盖**：转写讲过的都覆盖，**不因为"你没记"就略过**；废话/重复严压成通顺段落。
- **手写 = 你的重点**：手写命中的进正文、倾向强调；但范围仍由转写定（你没记的也覆盖）。
- **媒体读进正文**：图不是甩附件，是抽成文字；截图/课件能反向纠正转写易错项。
- **强调密度不塌**：斜体/`>`金句/表格是逐句判断的硬活，别滑成"列点平铺"。
- **不编造**网址/数字/版本号/人名；图模糊读不准的也存疑、不猜。拿不准的统一进末尾"可信度"栏。
- **说话人/时间不可信**；**文件名日期也不可信、以内容为准**。
- **飞书强调落笔即写对**：`*`/`**` 紧贴侧别留标点/引号/空格（脚本只兜底）。
- **多篇/长跑**：每篇做完立刻落盘 + 更新总导航 + 记进度（含未归位媒体），被 compact 也能续。

## 想固化某门课的约定？

某门课/某个长期项目有固定路径、固定术语表与资料表，**不要复制一份 skill**（会产生两个正本，正是本项目要消灭的）。把那些约定写进项目的宿主指令文件（如 `CLAUDE.md` 或 `AGENTS.md`）或进度文件，开工前先读。专属版优先，本通用版留作其它场景底座。
