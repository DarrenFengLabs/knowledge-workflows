# 阅读分诊的存储规则

优先从当前项目 `.local/paths.md` 取得 `$OUTPUT_DIR` 与 `$STAGING_DIR`；缺失时询问，不猜路径。过程抓取、索引、抽检记录和缓存进入本次 `$JOB_DIR`，最终只交付一份合并后的主文档。

## 命名

- 周期性增量导读：`📊<信源>导读_YYYY-MM-DD至MM-DD.md`
- 一次性专题总纲：`📚<信源>总纲_YYYY-MM至MM.md`

日期区间表示内容覆盖范围，而不是整理日期。信源使用稳定通称。成品默认写入 `$OUTPUT_DIR` 根目录；同名文件不覆盖。

## 过程稿

候选索引、逐篇摘记、筛选清单和聚类草稿是过程材料，最终应合并进主文档对应章节，不作为额外交付。合并前核对候选总量、排除理由、未读原文、覆盖率与结论证据是否仍可追溯。

成功后只清理本轮自己创建且确认无用户文件的 `$JOB_DIR`；失败时保留并报告。不得清理其他任务目录。
