# 模型表交接

仅在同时满足以下条件时，在导读或总纲末尾附“拟入表”：

1. 出现明确的模型型号、AI 工具或评测名称；
2. 至少有一个可复核硬锚点，例如官方页面、正式公告、技术报告、论文、API 文档、参数量、跑分、上下文、价格或发布日期。

纯观点、行业趋势、模糊系列名或只有营销描述时不提议。分诊阶段只生成提议，不写表。

```markdown
## 拟入表

拟新增 1 条 / 更新 0 条 / 建议归档 0 条

【新增】<明确型号或工具名>
- 已核实硬锚点：<事实 + 一手/二手来源>
- 未核实：<留空项或冲突项>
- 价值：<为何值得记录>
- 来源：<标题、链接、发布日期、发布方>

是否确认交给 model-table 处理？
```

每条必须区分“已核实”与“未核实”。用户确认后，由模型表流程重新查重、核验、备份、写入并回读。
